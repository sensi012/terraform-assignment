# Terraform

## Terraform Command
- terraform init: Initializes your working directory, downloads necessary plugins.
- terraform plan: Creates an execution plan, showing what actions Terraform will take.
- terraform apply: Applies the changes required to reach the desired state of the configuration.
- terraform destroy: Destroys all infrastructure resources defined in your configuration.
